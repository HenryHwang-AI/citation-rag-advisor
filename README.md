# 引溯 · 带引用的行业 RAG 顾问

给 AI 产品经理作品集用的静态演示。它扮演一个广告合规顾问：只根据本地知识库回答，每句结论带可点击的编号引用；知识库里没有依据，就明确拒答。

不调用模型 API，不需要密钥。用浏览器直接打开 `index.html` 即可离线使用。

## 你会看到什么

- **对话。** 中文问答。短追问会改写查询，把上一轮的术语补进去；换了主题则重新检索。
- **引用。** 回答里的编号可以点开。来源卡片给出标题、出处，以及高亮了检索词的原句。
- **检索轨迹。** 原问、改写、分词、BM25、重排分、过阈值还是拒答。
- **架构决策。** 分块、引用交互、拒答策略、评测集，以及为什么演示用词法检索。
- **评测。** 浏览器里跑内置金标，看 Recall@3、拒答准确率和引用忠实。

三个示例问题分别覆盖极限词与审核流程、医美疗效承诺、ROI 口径案例。

## 怎么打开

直接双击或用浏览器打开根目录的 `index.html`。

也可以起一个静态服务：

```bash
python3 -m http.server 8765
```

然后访问 `http://127.0.0.1:8765`。

页面不请求外部脚本、字体或接口。知识库内嵌在 `js/kb.js`，所以 `file://` 也能读。

## 知识库

`data/kb.json` 是 12 条合成材料，覆盖用语红线、医美与金融、审核 SOP、落地页一致性、未成年人、比较广告、直播话术、归因案例、广告标识、品牌安全和定向数据。

这些句子是为演示写的，不是法律法规原文，不能当作合规意见。

修改 JSON 后同步内嵌副本，并跑检索合约：

```bash
node scripts/sync-kb.js
node test/retrieval.test.js
```

不需要安装依赖。

## 检索在做什么

1. 领域词表做包含匹配，再加上重叠字二元组。带「的、了、是」的二元组丢掉。
2. BM25（k1 = 1.2，b = 0.72）。文档长度用字数。词表项的权重大于二元组。
3. 重排替身：`0.62 × 饱和 BM25 + 0.28 × 句级覆盖 + 0.10 × 标题命中`。饱和分是 `raw / (raw + 3)`，避免弱匹配被归一化成 1。
4. 没有低频词表命中，或重排分低于阈值，就拒答。除第一名外，引用还要命中问句里的低频词，避免只靠「落地页」这类宽词挂上不相关文档。

回答句是知识块里的原文，不是模型生成的转述。

## 目录

```

css/styles.css      界面
js/engine.js        分词、BM25、重排、拒答、评测
js/app.js           对话、引用卡片、轨迹
js/kb.js            内嵌知识库（由 data/kb.json 同步）
data/kb.json        知识库、示例问题、评测金标、词表
test/retrieval.test.js
scripts/sync-kb.js
```
